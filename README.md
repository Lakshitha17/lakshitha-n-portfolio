# Lakshitha's Tech Haven

Build a modern, clean, responsive personal portfolio website for Lakshitha N, an Aspiring Software Engineer and 2nd-year B.E. CSE (AI & ML) student at SRM MCET (Expected grad 2029, Madurai, Tamil Nadu).

Key sections and requirements:
- Navigation: Home, About, Skills, Learning, Problem Solving, Projects, Education, Leadership, Contact
- About Me: 2nd-year CSE (AI & ML) student focused on software development, Java, Full Stack Development, AI/ML, and problem solving.
- Skills: Categorized clean display of Java, C, C++, Python, JavaScript, HTML, CSS, SQL, MySQL, Git, GitHub, VS Code, DSA, Problem Solving.
- Currently Learning: Highlight ongoing learning in Java, Full Stack Development, DSA, and AI/ML.
- Problem Solving: Practicing beginner programming problems using JavaScript, C++, and Python.
- Projects: Strictly display an "Upcoming Projects" / "Work in Progress" showcase with concept previews instead of fake projects or placeholder stats.
- Education: SRM MCET, B.E. CSE (AIML), 2nd Year (2025–2029).
- Leadership & Activities: Joint Secretary – InnoVision Club (Dept of CSE AI&ML, SRM MCET); Event Coordinator – IdeaPitch, TECHERA'26; Technical event coordination.
- Contact & Socials: Email, GitHub, and LinkedIn buttons with clear placeholder link hooks ready to edit, plus a clean contact form.
- Design: Minimalist, professional, student and recruiter-friendly, smooth scrolling, subtle animations, fully mobile-responsive with light/dark theme toggle.
